# Chat

Chat is available to every signed-in person. An administrator turns it on from Settings by saving a provider, a model, and an API key. Until that is saved, Chat shows an AI not available card. The message box is disabled. An administrator also sees a link to Settings on that card. Chats that already exist stay in the list and can still be opened.

Opening Chat from another page returns to the last chat you opened. The list and the thread fill the main area. Only the thread scrolls, and the message box stays at the bottom of that thread. While the list or a transcript is still loading, placeholders stand in for the rows and the messages. Opening another chat clears the previous transcript immediately. On a wide screen the list stays beside the thread. On a small screen the list stays hidden until you open Chats, which slides in from the side like the main menu. New chat sits next to that button.

A blank chat offers three starters: Create a short link, Create a campaign, and Analytics report. Each one has a short line under the label. Choosing one sends that request. The title of an open chat is the name of that transcript. Each assistant reply is one card. Headings, text, tables, charts, and a form sit in that card.

The short-link form asks for the destination, an optional title, an optional custom slug, UTM source, medium, and campaign, and whether to create a QR code. The slug, title, and UTM fields can be skipped. Suggest UTM sits above those three UTM fields when AI is on. An optional line says where the link will be shared. The button fills source, medium, and campaign. You can change them before you submit. If the request already includes a destination, Sharry reads that page and fills in a free slug. The buttons inside the title and slug fields do the same for the destination typed in the form, and they are shown only when AI is turned on. A suggested slug is at most three words. A tooltip says where the suggestion came from. If Sharry cannot suggest a slug, that message stays in the tooltip on the slug field. You can change the suggestion. Submitting the form creates the link and stores the title and UTM values. If you checked the box, it also saves a QR code. The same card then shows the short URL, a button to copy it, and a button to open it. A slug that is already in use stays on the form so you can change it.

The analytics form asks whether the report is for all links or one link. One link opens a list of your links. A slider with two ends sets the dates. The track runs from the day that link was created, or from the oldest link you can see, through today. It starts on the last 30 days unless you already named dates. A range longer than 400 days asks you to narrow it. The reply starts with a short explanation of that range and the totals. The same card then shows clicks by day and bar charts for referrers, countries, browsers, devices, operating systems, bots, and UTM fields. An all-links report also lists each link. Open analytics and Export to PDF are buttons under that report. Export to PDF downloads `sharry-analytics.pdf`.

The campaign form asks for a name, an optional link from that same list, and an optional variant name. Submitting it creates the campaign.

Older confirmation cards still work. The rest of the task stays in the chat. A page you could not find, and an explanation of a screen, also include a link you can open. Before it asks for a clearer name, the assistant searches the links, campaigns, chats, and pages that person can open, including when the name is mistyped. The chat does not send you away on its own.

The message box stays at the bottom of the thread. Enter sends. Shift+Enter starts a new line. The box grows as you type. If you scroll up, Jump to latest returns to the newest line. While a reply is being written, Stop ends it. A send that fails stays in the thread with Retry.

The assistant only answers questions about Sharry. A request to write an app, write code, or answer something unrelated gets a short refusal and no further help.

New chat is at the top of the list. It starts a blank transcript and does not replace the remembered chat until you open one. Delete chat asks before it removes that transcript. Each person sees only their own chats. A person can send 40 messages an hour.
