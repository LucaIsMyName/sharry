# Chat

Chat is available to every signed-in person. An administrator turns it on from Settings by saving a provider, a model, and an API key. Until that is saved, Chat shows an AI not available card. The message box is disabled. Chats that already exist stay in the list and can still be opened.

Opening Chat from another page returns to the last chat you opened. On a wide screen that list stays beside the thread and scrolls on its own. On a small screen the list stays hidden until you open Chats, which slides in from the side like the main menu.

A blank chat offers three starters: Create a short link, Create a campaign, and Analytics report. Choosing one sends that request. Each assistant reply is one card. Headings, text, tables, charts, and a form sit in that card.

The short-link form asks for the destination, an optional custom slug, and whether to create a QR code. The slug can be skipped. If the request already includes a destination, Sharry reads that page and fills in a free slug. The button inside the slug field does the same for the destination typed in the form. You can change the suggestion. Submitting the form creates the link. If you checked the box, it also saves a QR code. The same card then shows the short URL and a link to open it. A slug that is already in use stays on the form so you can change it.

The analytics form asks whether the report is for all links or one link. One link opens a list of your links. The report uses the last 30 days unless you already named dates. The reply starts with a short explanation of that range, the totals, the clicks-by-day chart, and the table. The chart and the table follow in the same card, with a link to the analytics page.

The campaign form asks for a name, an optional link from that same list, and an optional variant name. Submitting it creates the campaign.

Older confirmation cards still work. The rest of the task stays in the chat. A page you could not find, and an explanation of a screen, also include a link you can open. The chat does not send you away on its own.

The message box stays at the bottom of the screen. Enter sends. Shift+Enter starts a new line. The box grows as you type.

The assistant only answers questions about Sharry. A request to write an app, write code, or answer something unrelated gets a short refusal and no further help.

New chat starts a blank transcript and does not replace the remembered chat until you open one. Delete chat removes that transcript. Each person sees only their own chats. A person can send 40 messages an hour.
