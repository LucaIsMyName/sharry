# Chat

Chat is available to every signed-in person. An administrator turns it on from Settings by saving a provider, a model, and an API key. Until that is saved, Chat shows an AI not available card. The message box is disabled. Chats that already exist stay in the list and can still be opened.

A blank chat offers three starters: Create a short link, Create a campaign, and Analytics report. Choosing one sends that request and the assistant asks for the next missing piece, one question at a time. It says when a title, a slug, or a variant can be skipped.

Creating a link or a campaign does not happen until you confirm the card in the chat. The card shows what will be created. Confirm creates it and the same card then shows the short URL, or the campaign, and a link to open it. Dismiss leaves it uncreated. The rest of the task stays in the chat. A report, a page you could not find, and an explanation of a screen also include a link you can open. The chat does not send you away on its own.

The assistant only answers questions about Sharry. A request to write an app, write code, or answer something unrelated gets a short refusal and no further help.

New chat starts another transcript. Delete chat removes that transcript. Each person sees only their own chats. A person can send 40 messages an hour.
