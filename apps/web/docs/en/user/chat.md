# Chat

Chat is available to every signed-in person. An administrator turns it on from Settings by saving a provider, a model, and an API key. Until that is saved, Chat shows an AI not available card. The message box is disabled. Chats that already exist stay in the list and can still be opened.

A blank chat offers three starters: Create a short link, Create a campaign, and Analytics report. Choosing one sends that request. The assistant answers with text, headings, tables, and a form in the chat.

The short-link form asks for the destination, an optional custom slug, and whether to create a QR code. The slug can be skipped. Submitting the form creates the link. If you checked the box, it also saves a QR code. The same card then shows the short URL and a link to open it. A slug that is already in use stays on the form so you can change it.

The analytics form asks whether the report is for all links or one link. One link opens a list of your links. The report uses the last 30 days unless you already named dates, and it says which range it used. The answer includes a heading, a click chart, and a table, plus a link to the analytics page.

The campaign form asks for a name, an optional link from that same list, and an optional variant name. Submitting it creates the campaign.

Older confirmation cards still work. The rest of the task stays in the chat. A page you could not find, and an explanation of a screen, also include a link you can open. The chat does not send you away on its own.

The message box stays at the bottom of the screen. Enter sends. Shift+Enter starts a new line. The box grows as you type.

The assistant only answers questions about Sharry. A request to write an app, write code, or answer something unrelated gets a short refusal and no further help.

New chat starts another transcript. Delete chat removes that transcript. Each person sees only their own chats. A person can send 40 messages an hour.
