# Search

Search sits in the sidebar under Chat. Cmd+K opens it on a Mac. Ctrl+K opens it on other systems.

With nothing typed, the palette lists the pages you can open. Administrators also see Users, API keys, Settings, Domains, Server, and Audit. Sign-in and password-reset pages stay out. Each result uses the icon of the page it opens. A link or campaign uses its own icon when one is set. A long title stays inside the dialog. A short link also shows its slug, destination, and description.

Typing searches further:

- Links, by title, description, slug, destination, a routing rule name, a UTM value, or a QR code name. A match opens the link. The same link is listed under Analytics, which opens that link’s clicks. The Analytics page itself is the total for every link you can see.
- Campaigns, by name, description, or a variant name.
- Your own chats, by title or message text.
- The docs in your language, by title or page text.
- Sections on Account and Settings, such as password, two-factor authentication, the public prefix, and the mail server.
- For an administrator: users, domains, API keys by name or the visible prefix, and audit rows. Choosing one opens that page and highlights the row. An older audit row is loaded even when it is past the first page.

Search does not look at passwords, two-factor secrets, recovery codes, or API key secrets.
