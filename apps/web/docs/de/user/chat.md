# Chat

Der Chat steht jeder angemeldeten Person zur Verfügung. Eine Administratorin oder ein Administrator schaltet ihn in den Einstellungen ein, indem ein Anbieter, ein Modell und ein API-Schlüssel gespeichert werden. Bis das gespeichert ist, zeigt der Chat die Karte KI nicht verfügbar. Das Nachrichtenfeld ist deaktiviert. Eine Administratorin oder ein Administrator sieht auf dieser Karte außerdem einen Link zu den Einstellungen. Chats, die schon existieren, bleiben in der Liste und lassen sich weiter öffnen.

Wer den Chat von einer anderen Seite aus öffnet, kommt zum zuletzt geöffneten Chat zurück. Liste und Gespräch füllen den Hauptbereich. Nur das Gespräch scrollt, und das Nachrichtenfeld bleibt unten in dieser Spalte. Solange die Liste oder ein Gespräch noch lädt, stehen Platzhalter für die Zeilen und die Nachrichten. Ein anderes Gespräch öffnen räumt das vorige sofort weg. Auf einem breiten Bildschirm bleibt die Liste neben dem Gespräch. Auf einem kleinen Bildschirm bleibt sie verborgen, bis du Chats öffnest. Das Menü gleitet von der Seite herein, wie das Hauptmenü. Neuer Chat sitzt neben diesem Knopf.

Ein leerer Chat bietet drei Einstiege: Kurzlink anlegen, Kampagne anlegen und Auswertung. Unter jedem steht eine kurze Zeile. Wer einen wählt, schickt diese Anfrage. Der Titel eines offenen Chats ist der Name dieses Gesprächs. Jede Antwort der Assistenz ist eine Karte. Überschriften, Text, Tabellen, Diagramme und ein Formular stehen in dieser Karte.

Das Kurzlink-Formular fragt nach dem Ziel, einem optionalen Titel, einem optionalen eigenen Slug, UTM-Quelle, Medium und Kampagne und ob ein QR-Code erzeugt werden soll. Slug, Titel und UTM-Felder können ausgelassen werden. Steht in der Anfrage schon ein Ziel, liest Sharry diese Seite und füllt einen freien Slug ein. Die Knöpfe im Titel- und im Slug-Feld machen dasselbe für das Ziel, das im Formular steht, und sie erscheinen nur, wenn die KI eingeschaltet ist. Ein Tooltip sagt, woher der Vorschlag kommt. Den Vorschlag kannst du ändern. Absenden legt den Link an und speichert Titel und UTM-Werte. Ist das Kästchen gesetzt, speichert es auch einen QR-Code. Dieselbe Karte zeigt danach die Kurz-URL, einen Knopf zum Kopieren und einen Knopf, um sie zu öffnen. Ein Slug, der schon vergeben ist, bleibt im Formular, damit du ihn ändern kannst.

Das Auswertungsformular fragt, ob der Bericht alle Links oder einen Link betrifft. Ein Link öffnet eine Liste deiner Links. Ein Schieberegler mit zwei Enden setzt die Daten. Die Spur läuft vom Tag, an dem dieser Link angelegt wurde, oder vom ältesten Link, den du sehen kannst, bis heute. Sie beginnt mit den letzten 30 Tagen, außer du hast schon Daten genannt. Ein Zeitraum länger als 400 Tage bittet dich, ihn enger zu fassen. Die Antwort beginnt mit einer kurzen Erklärung dieses Zeitraums und der Summen. Dieselbe Karte zeigt danach die Klicks pro Tag und Balkendiagramme für Verweise, Länder, Browser, Geräte, Betriebssysteme, Bots und UTM-Felder. Ein Bericht über alle Links listet außerdem jeden Link. Auswertung öffnen und Als PDF exportieren sind Knöpfe unter diesem Bericht. Als PDF exportieren lädt `sharry-analytics.pdf` herunter.

Das Kampagnenformular fragt nach einem Namen, einem optionalen Link aus derselben Liste und einem optionalen Variantennamen. Absenden legt die Kampagne an.

Ältere Bestätigungskarten funktionieren weiter. Der Rest der Aufgabe bleibt im Chat. Eine Seite, die du nicht gefunden hast, und eine Erklärung eines Bildschirms enthalten ebenfalls einen Link, den du öffnen kannst. Bevor die Assistenz nach einem klareren Namen fragt, sucht sie in den Links, Kampagnen, Chats und Seiten, die diese Person öffnen kann, auch wenn der Name vertippt ist. Der Chat schickt dich nicht von selbst weg.

Das Nachrichtenfeld bleibt unten im Gespräch. Eingabetaste sendet. Umschalt+Eingabetaste beginnt eine neue Zeile. Das Feld wächst beim Tippen. Wer nach oben scrollt, kommt mit Zum Neuesten zurück zur letzten Zeile. Während eine Antwort geschrieben wird, beendet Stopp sie. Ein Senden, das scheitert, bleibt im Gespräch mit Erneut versuchen.

Die Assistenz beantwortet nur Fragen zu Sharry. Eine Bitte, eine App zu schreiben, Code zu schreiben oder etwas anderes zu beantworten, bekommt eine kurze Absage und keine weitere Hilfe.

Neuer Chat steht oben in der Liste. Er startet ein leeres Gespräch und ersetzt den gemerkten Chat nicht, bis du einen öffnest. Chat löschen fragt, bevor es dieses Gespräch entfernt. Jede Person sieht nur die eigenen Chats. Eine Person kann 40 Nachrichten pro Stunde senden.
