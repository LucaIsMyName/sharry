# Chat

Der Chat steht jeder angemeldeten Person zur Verfügung. Eine Administratorin oder ein Administrator schaltet ihn in den Einstellungen ein, indem ein Anbieter, ein Modell und ein API-Schlüssel gespeichert werden. Bis das gespeichert ist, zeigt der Chat die Karte KI nicht verfügbar. Das Nachrichtenfeld ist deaktiviert. Chats, die schon existieren, bleiben in der Liste und lassen sich weiter öffnen.

Ein leerer Chat bietet drei Einstiege: Kurzlink anlegen, Kampagne anlegen und Auswertung. Wer einen wählt, schickt diese Anfrage, und die Assistenz fragt nach dem nächsten fehlenden Teil, eine Frage nach der anderen. Sie sagt, wann ein Titel, ein Slug oder eine Variante ausgelassen werden kann.

Ein Link oder eine Kampagne entsteht erst, wenn du die Karte im Chat bestätigst. Die Karte zeigt, was angelegt wird. Bestätigen legt es an, und dieselbe Karte zeigt danach die Kurz-URL oder die Kampagne und einen Link, um sie zu öffnen. Verwerfen legt nichts an. Der Rest der Aufgabe bleibt im Chat. Eine Auswertung, eine Seite, die du nicht gefunden hast, und eine Erklärung eines Bildschirms enthalten ebenfalls einen Link, den du öffnen kannst. Der Chat schickt dich nicht von selbst weg.

Die Assistenz beantwortet nur Fragen zu Sharry. Eine Bitte, eine App zu schreiben, Code zu schreiben oder etwas anderes zu beantworten, bekommt eine kurze Absage und keine weitere Hilfe.

Neuer Chat startet ein weiteres Gespräch. Chat löschen entfernt dieses Gespräch. Jede Person sieht nur die eigenen Chats. Eine Person kann 40 Nachrichten pro Stunde senden.
