# Chat

Der Chat steht jeder angemeldeten Person zur Verfügung. Eine Administratorin oder ein Administrator schaltet ihn in den Einstellungen ein, indem ein Anbieter, ein Modell und ein API-Schlüssel gespeichert werden. Bis das gespeichert ist, zeigt der Chat die Karte KI nicht verfügbar. Das Nachrichtenfeld ist deaktiviert. Chats, die schon existieren, bleiben in der Liste und lassen sich weiter öffnen.

Ein leerer Chat bietet drei Einstiege: Kurzlink anlegen, Kampagne anlegen und Auswertung. Wer einen wählt, schickt diese Anfrage. Die Assistenz antwortet mit Text, Überschriften, Tabellen und einem Formular im Chat.

Das Kurzlink-Formular fragt nach dem Ziel, einem optionalen eigenen Slug und ob ein QR-Code erzeugt werden soll. Der Slug kann ausgelassen werden. Absenden legt den Link an. Ist das Kästchen gesetzt, speichert es auch einen QR-Code. Dieselbe Karte zeigt danach die Kurz-URL und einen Link, um sie zu öffnen. Ein Slug, der schon vergeben ist, bleibt im Formular, damit du ihn ändern kannst.

Das Auswertungsformular fragt, ob der Bericht alle Links oder einen Link betrifft. Ein Link öffnet eine Liste deiner Links. Der Bericht nutzt die letzten 30 Tage, außer du hast schon Daten genannt, und er sagt, welchen Zeitraum er verwendet. Die Antwort enthält eine Überschrift, ein Klickdiagramm und eine Tabelle, plus einen Link zur Auswertungsseite.

Das Kampagnenformular fragt nach einem Namen, einem optionalen Link aus derselben Liste und einem optionalen Variantennamen. Absenden legt die Kampagne an.

Ältere Bestätigungskarten funktionieren weiter. Der Rest der Aufgabe bleibt im Chat. Eine Seite, die du nicht gefunden hast, und eine Erklärung eines Bildschirms enthalten ebenfalls einen Link, den du öffnen kannst. Der Chat schickt dich nicht von selbst weg.

Das Nachrichtenfeld bleibt unten auf dem Bildschirm. Eingabetaste sendet. Umschalt+Eingabetaste beginnt eine neue Zeile. Das Feld wächst beim Tippen.

Die Assistenz beantwortet nur Fragen zu Sharry. Eine Bitte, eine App zu schreiben, Code zu schreiben oder etwas anderes zu beantworten, bekommt eine kurze Absage und keine weitere Hilfe.

Neuer Chat startet ein weiteres Gespräch. Chat löschen entfernt dieses Gespräch. Jede Person sieht nur die eigenen Chats. Eine Person kann 40 Nachrichten pro Stunde senden.
