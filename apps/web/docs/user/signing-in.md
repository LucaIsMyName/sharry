# Signing in

Registration is closed. An administrator creates each account and sets a temporary password. The first sign-in asks for a new password before the dashboard opens. On that page, Generate password fills a 16-character password you can keep. An administrator can later set a new temporary password for any account, including another administrator. That ends the person's current sign-in. Deleting an account also removes that person's links, campaigns, QR codes, and API keys. Deactivate keeps the account and its data, but blocks sign-in.

Sign in with a username or an email address. Two-factor authentication stays off until you turn it on from Account, or an administrator requires it in Settings. Setup shows a QR code and the secret, and both can be copied. Recovery codes can be copied as a set. When a code is required, sign-in continues after the authenticator code or a recovery code.

Password reset email uses the mail server saved in Settings. Until a host and from address are saved there, Sharry can fall back to the server environment. Asking for another reset email replaces the previous unused link.
