# Signing in

Registration is closed. An administrator creates each account and sets a temporary password. The first sign-in asks for a new password before the dashboard opens.

Sign in with a username or an email address. Two-factor authentication stays off until you turn it on from Account, or an administrator requires it in Settings. When a code is required, sign-in continues after the authenticator code or a recovery code.

Password reset email uses the mail server saved in Settings. Until a host and from address are saved there, Sharry can fall back to the server environment. Asking for another reset email replaces the previous unused link.
